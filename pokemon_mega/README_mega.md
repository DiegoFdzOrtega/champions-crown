# Sprites de megaevoluciones (SpriteCollab)

Sprites estilo *Pokémon Mundo Misterioso* de **PMD SpriteCollab** (https://github.com/PMDCollab/SpriteCollab), licencia **CC BY-NC 4.0** (dar crédito a los artistas; sin uso comercial). El `credits.txt` de cada carpeta dice quién los dibujó.

Mismo formato que `pokemon/`: `Idle.png`, `Walk.png`, `Attack.png`, `Shoot.png`, `Charge.png`, `Hurt.png`, `Faint.png`, y `s/` con la versión shiny. Cada carpeta se llama `<nº Pokédex>-<forma>` (ej. `6-mega-x`).

**Aún NO están conectados al juego.** Solo son los archivos.
